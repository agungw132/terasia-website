PERANGKAT ANDA SUDAH SAMPAI MANA?

Empat tahap. Kenali posisi Anda.

Setiap rumah dan workshop mulai dari tempat yang sama: perangkat yang bekerja sendiri-sendiri. Terasia menuntaskan tiga tahap pertama secara otomatis — tahap keempat jadi milik Anda.

TAHAP 01

Berkedip sendiri

Sensor, switch, dan kamera bekerja — tapi datanya menguap begitu layar perangkat berganti. Tidak ada sejarah, tidak ada pola.

Biaya tersembunyi: keputusan berdasar tebakan.

TAHAP 02

Terhubung

Semua perangkat publish ke satu broker MQTT — TLS untuk perangkat rumah, mTLS untuk perangkat produksi. Kredensial per perangkat, isolasi per tenant.

Ciri: satu titik masuk, nol konfigurasi manual.

TAHAP 03

Terkumpul

Telemetry mengalir ke dashboard real-time dan terarsip otomatis sebagai parquet — bertahun-tahun kemudian masih bisa di-query dalam hitungan detik.

Ciri: data lama bukan arsip mati.

TAHAP 04

Agentic

Anda tidak lagi membaca grafik satu per satu. Tanya dalam bahasa biasa — "berapa kWh kemarin dibanding minggu lalu?" — asisten menjawab dengan data Anda sendiri.

Ciri: data mengerjakan, Anda memutuskan.

SATU PLATFORM, SEMUA KEBUTUHAN TELEMETRY

Apa yang Terasia kerjakan untuk Anda

📈

Dashboard real-time

Daya, energi, suhu, kehadiran — semua sensor tampil langsung di dashboard Grafana. Melihat konsumsi listrik per jam bukan lagi pekerjaan manual.

🗄️

Arsip yang hidup

Setiap pesan telemetry dikompresi jadi parquet harian di object storage. Data dua tahun lalu tetap bisa di-query — bukan cuma disimpan.

💬

Asisten AI "Tera"

Tanya data dalam bahasa sehari-hari. Tera menerjemahkan pertanyaan Anda menjadi query ke arsip Anda sendiri — dan hanya milik Anda.

🔬

Notebook analisis

Untuk yang ingin menggali lebih dalam: notebook Jupyter pribadi per user, langsung tersambung ke data Anda dengan isolasi penuh.

🔔

Alerting

Atur aturan di atas telemetry Anda — daya melebihi ambang, sensor diam terlalu lama — dan terima notifikasi sebelum masalah membesar.

🧩

Playground MQTT

Publish dan listen langsung dari browser untuk uji perangkat baru — tanpa install client, tanpa keluar dari portal.

EMPAT LANGKAH. BISA DICEK.

Dari perangkat pertama ke asisten pribadi

Setiap langkah punya keluaran yang bisa Anda pegang. Tidak ada tahap yang selesai tanpa bukti.

01

Sambungkan perangkat

Daftar di portal, kredensial MQTT dibuat otomatis. Perangkat rumah lewat TLS (port 8883), perangkat produksi lewat mTLS dengan client certificate yang Anda terbitkan sendiri dari portal.

Keluaran: perangkat online di daftar device Anda.

02

Data mengalir

Telemetry masuk lewat broker MQTT, tersimpan real-time untuk dashboard dan terarsip otomatis ke object storage. Anda tidak mengelola apa pun.

Keluaran: grafik hidup + arsip harian yang terlihat di file browser.

03

Jelajahi

Dashboard untuk memantau, notebook untuk menganalisis, file browser untuk mengunduh data mentah. Semua dari satu portal, satu login.

Keluaran: Anda tahu apa yang sebenarnya terjadi di rumah Anda.

04

Tanya Tera

Asisten AI Tera siap menjawab pertanyaan atas data Anda sendiri — dalam bahasa Indonesia, tanpa SQL, tanpa spreadsheet.

Keluaran: jawaban terverifikasi dari data Anda, bukan tebakan.

DATA RUMAH ADALAH DATA PRIBADI

Keamanan bukan fitur tambahan

🔐 Isolasi per tenant

Data Anda difilter di layer server — bukan cuma di tampilan. Tenant lain tidak bisa membaca topik Anda, titik. Query ke folder tenant lain diblokir di sisi database.

📜 TLS & mTLS

Perangkat terenkripsi end-to-end: TLS dengan password untuk rumah, mutual TLS dengan certificate per perangkat untuk instalasi serius.

🏠 Data Anda tetap milik Anda

Arsip tersimpan sebagai file parquet terbuka — format standar, bukan lock-in. Unduh kapan saja lewat file browser.

Mulai dari satu sensor hari ini.
